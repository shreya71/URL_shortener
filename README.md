# Overview
This is a simple URL shortener application that allows users to convert long URLs into shorter, more manageable links. The application is built with Node.js, Express.js, and a hashing algorithm.

# Features
 - Shorten long URLs to compact, easy-to-share links
 - Redirect short URLs to their original destination

# Installation

1. Clone this repository
  ```
  git clone https://github.com/shreya71/URL_shortener.git
  cd url-shortener
  ```

2. Install npm dependencies
  ```
  npm install
  ```

3. Use nodemon for live reload
  ```
  npm start
  ```
